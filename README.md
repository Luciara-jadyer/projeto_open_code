# Projeto Open Code — Pipeline, Análise de Dados e Dashboard

## Sobre o projeto

Projeto prático desenvolvido para explorar o uso de ferramentas de IA no apoio ao desenvolvimento de uma solução de dados.

A proposta utiliza o Open Code como alternativa gratuita para ferramentas de desenvolvimento assistido por IA, aplicando o recurso na construção de uma solução envolvendo geração, processamento, armazenamento, análise e visualização de dados.

## Objetivo

Desenvolver uma solução integrada para trabalhar com dados desde sua geração e processamento até a apresentação dos resultados por meio de relatórios e dashboard.

## Estrutura da solução

O projeto está organizado em diferentes etapas:

* Geração de dados;
* Processamento e preparação dos dados;
* Pipeline de dados;
* Armazenamento em banco de dados;
* Geração de relatórios;
* Visualização dos resultados em dashboard.

## Tecnologias utilizadas

* Python
* SQLite
* Dashboard
* Análise de dados
* Visualização de dados
* Open Code
* Git/GitHub

## Arquivos principais

`gerar_dados.py`
Responsável pela geração dos dados utilizados no projeto.

`pipeline.py`
Responsável pelo processamento e fluxo dos dados.

`relatorio.py`
Utilizado para geração dos relatórios.

`dashboard.py`
Responsável pela apresentação visual dos resultados.

`database.db`
Banco de dados utilizado no projeto.

`requirements.txt`
Lista das dependências utilizadas na aplicação.

## Aprendizados

O desenvolvimento deste projeto permitiu praticar conceitos relacionados ao processamento de dados, construção de pipelines, armazenamento, geração de relatórios e visualização de informações.

Também possibilitou explorar o uso de ferramentas de Inteligência Artificial como apoio ao desenvolvimento de soluções tecnológicas.
